What each one does

  • A1, a divider line. The simplest: a thin line under the box, then everything else on the same background. The cheapest, but the box and the tiles still read as one long list.
  • A2, two zones (recommended). The box and the four action tiles sit in a white top panel, and the spaces sit below it on the grey background. "Ask or act" is visibly separate from "browse". There is room for a short 🔒 Passwords go in the Vault hint at the bottom left of the box, opposite 🎤 and Send, which settles U7 without an extra line.
  • A3, box + pills. The actions shrink to small pills under the box, so the spaces start higher up the screen. The pills are lighter but smaller to tap than tiles.
  • Same in all three: the box grows from 3 lines up to about 6 as you type, then scrolls. Return adds a new line, and only ↑ sends. Dictation still fills the box, and the password reminder still shows while you dictate. 📍 stays a tile, so home still never reads your location except on that tap (places Q10).

Cost: the same as Option A (PR 3 grows a little: a multi-line box with its buttons inside). A2 adds one panel style.

Recommended: Home A + Chat A, in six small PRs

App only, no server change. Each PR passes npm run check and is tried in the browser preview. All six ship together in one Play build, with one short phone checklist.

  1. Shared pieces in ui.tsx: IconButton, TextLink, Tile, GroupList, and one spacing scale. Nothing on screen changes yet. Model: Sonnet
  2. Settings screen (/settings): meter, signed in as, change password, recycle bin, sign out, version. Home gets ⚙ and drops its footer. Sonnet
  3. Home tidy: the action tiles (Chat, New note, Save here, Vault), round mic and send, spaces as a grouped list, and a one-line restricted row. Sonnet
  4. Chat composer: icon buttons, one status chip, the always-visible password line with its Vault link, and "New chat". It touches the password guidance and the 📍 wiring. Strongest model
  5. Chat cards: one ChatCard shell for vault, notes, delete and error cards; buttons side by side. It touches the vault and delete cards. Strongest model
  6. Phone checklist (docs/ui-tidy-phone-checklist.md), then "build for Play" when you say so. Sonnet

Places step 8 (place cards and the "📍 Share where I am" card) then builds on the card shell from PR 5. Doing PR 5 first saves building those cards twice.
